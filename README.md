# Skye Harvey — marketing & events portfolio

A static, client-side portfolio page covering Skye Harvey's brand, social media
and event work for The Bodyweight Gym, a calisthenics studio in Osborne Park,
Perth, from 2017 to 2021.

No build step, no dependencies, no framework. Open `index.html`, or serve the
directory:

```
python3 -m http.server 8000
```

```
index.html            the page
assets/css/styles.css
assets/js/main.js     nav, feed filter, section highlighting
assets/img/           images from the gym's own channels
NOTES.md              outstanding gaps, sources, and decisions to confirm
```

See [NOTES.md](NOTES.md) before publishing — it lists the handful of figures
still to fill in and how to reveal them in place.
